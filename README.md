# Personal Creative Portfolio

A responsive, light-themed portfolio website for graphic design, scriptwriting, Amharic–English translation, and tutoring in spoken English and IT.

## Before publishing

1. Replace `YOUR NAME` throughout `index.html` with your professional name.
2. Replace `YOUR-EMAIL@example.com` with an email address you want employers and clients to use.
3. Replace the three graphic-design placeholder tiles with images of your own work. Put image files in `images/` and use descriptive alt text.
4. Personalize the About section so it reflects your real skills and experience.
5. Keep concept projects labelled as samples; do not imply that practice samples were commissioned by clients.
6. Review all language examples and only offer translation or tutoring in areas you can confidently support.

## Publish with GitHub Pages

1. Sign in to GitHub and create a repository named exactly `YOUR-USERNAME.github.io`, replacing the placeholder with your GitHub username.
2. Upload `index.html`, `style.css`, this README, and the `images` and `samples` folders to the repository's root.
3. Open **Settings → Pages**. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the deployment to finish. Your site should appear at `https://YOUR-USERNAME.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart
